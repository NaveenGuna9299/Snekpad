# SnekPad v0.3.0

## SnekPad Studio (desktop app)

- **New Windows installer.** The installer is now a miniature SnekPad: the 12 RGB keys light up as files install and an OLED-style display shows the progress. It installs for the current user, lets you change the install folder, and has a Launch button at the end. Under the hood it runs the standard installer silently, so shortcuts and uninstalling work as before. The file is now called `SnekPad-Studio-Setup-0.3.0.exe`.
- The macOS and Linux installers are unchanged.

## Notes

- This version has the same pad firmware as v0.1.0. Nothing needs to change on the pad.
- Config schema version: 1 (unchanged).
- The Windows, macOS and Linux installers are not code-signed. See the README for how to open them.
